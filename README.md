# 🎮 XO Game – Tic Tac Toe

## 📌 Project Description
XO Game is a simple and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript. Two players take turns marking X and O in a 3×3 grid. The first player to match three symbols horizontally, vertically, or diagonally wins the game.

## 🚀 Features
- Simple and user-friendly interface.
- Two-player gameplay.
- Interactive 3×3 game board.
- Automatic winner detection.
- Draw detection.
- Restart game option.
- Responsive design.

## 🛠️ Technologies Used
- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and functionality.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start playing the XO Game!

## 🎯 How to Play
1. Player 1 uses X.
2. Player 2 uses O.
3. Players take turns selecting empty boxes.
4. The first player to get three matching symbols wins.
5. If all boxes are filled without a winner, the game ends in a draw.
